# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.1.x   | Yes       |
| < 1.1   | No        |

## Reporting a vulnerability

Please report security issues **privately** to **elena.konkova.dev@gmail.com**. Do not open a public issue for undisclosed vulnerabilities.

Include: description, steps to reproduce, and impact if known. Expect an initial response within 14 days.

## Scope

This repository contains **synthetic research code** only. No patient data, credentials, or production clinical systems are in scope.
